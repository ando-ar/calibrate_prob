calibration pipeline demo

紹介候補スコアの確率校正を試すデモです。ボタンを押すと本物のCLI（python -m calibration_pipeline.cli）が別プロセスで動き、完了まで待ちます。生成物は experiments/demo_gui/ に保存されます。

学習で何が起きるか

入力experiment名、学習config.toml（対象スコア・ラベル・確率列・特徴量・bins）、train.sql（row_role=train / calibrate / validation の3区分を1表で返す）、seed、sqlite fixture（任意）
実行python -m calibration_pipeline.cli train --model-name ... --sqlite ...
出力experiments/demo_gui/<model>/train/<run_id>/output/ に calibration_model.pkl、calibration_metrics.json（件数・実績率・ECE・Brier・ビン毎の予測平均と実績率）、calibration_plot.svg。train区分でCatBoostを学び、calibrate区分の出力にIsotonic Regressionを当て、validation区分で比較します。

推論で何が起きるか

入力experiment名、使用する学習run（最新または選択）、inference.sql（一時テーブル calibration_candidates から candidate_row_id・元スコア・特徴量を返す）、元スコアCSV（1行1候補）、seed、sqlite fixture（任意）
実行python -m calibration_pipeline.cli inference --model-name ... --sqlite ...
出力experiments/demo_gui/<model>/inference/<run_id>/output/ に calibrated_score.csv（入力と同じ形式・行順で、末尾に予測確率列）。推論の列契約は学習済みモデルから読み込まれるため、推論configは空またはコメントのみです。
