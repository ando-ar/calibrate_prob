calibration-pipeline

既存の求人紹介スコアを、CatBoostとIsotonic Regressionで確率に校正するバッチです。 応募・書類通過・決定などの元モデルごとにexperimentを作り、学習・推論の入力と結果を保存します。

初めて使う場合はクイックスタートを、Pythonから呼び出す場合はAPIリファレンスを参照してください。

  • クイックスタート
    • SQLiteで学習と推論を試す
    • Redshiftで実行する
  • 入力・出力と実行の流れ
    • 学習
    • 推論
    • experimentと再現
