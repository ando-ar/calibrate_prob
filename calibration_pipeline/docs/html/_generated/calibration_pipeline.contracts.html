calibration_pipeline.contracts.categorical_text(values: Series, name: str) → Series[ソース]

Map one categorical column to its training-time string form.

The user decides per column whether a code such as 1, 2, 3 is an order (numeric feature) or a category (this list). Numeric values become stable strings here, so an integer in the training SQL and its string spelling in a candidate CSV land in the same category.
