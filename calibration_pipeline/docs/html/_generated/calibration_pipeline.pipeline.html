calibration_pipeline.pipeline.fit(config: Config, frames: dict[str, DataFrame], seed: int) → Calibrator[ソース]

train区分でCatBoostを学習し、calibrate区分でその出力を校正する。

パラメータ:

  • config -- 元スコア、特徴量、ラベルの列契約。

  • frames -- 検証済みの train と calibrate のDataFrame。

  • seed -- CatBoostの乱数seed。

戻り値:

学習済みモデル。校正範囲外の入力は端の値にクリップする。

calibration_pipeline.pipeline.train(experiments_dir: Path, model_name: str, config_path: Path, sql_path: Path, *, sqlite: bool = False, seed: int = 42, sqlite_fixture: Path | None = None) → Path[ソース]

入力を保存し、SQL抽出・学習・評価を実行して学習runのパスを返す。

config_path は学習TOML、sql_path はtrain/calibrate/validationを 返すSQL。sqlite=True ならSQLiteを、既定では環境変数のRedshiftを使う。 sqlite_fixture を指定するとDBのコピーを入力として保存する。 失敗時は例外を送出し、入力と失敗状態をrunに残す。

calibration_pipeline.pipeline.inference(experiments_dir: Path, model_name: str, config_path: Path, sql_path: Path, original_score: Path, *, train_run: str | None = None, sqlite: bool = False, seed: int = 42, sqlite_fixture: Path | None = None) → Path[ソース]

保存済みモデルで候補を校正し、推論runのパスを返す。

original_score は候補CSVまたはParquet。config_path は空のTOML、 sql_path は候補の元スコアと特徴量を返すSQLを指定する。 train_run を省略すると、開始時刻が最も新しい成功済み学習runを使う。 出力は入力と同じ形式・行順で確率列を追加する。 pickleモデルは信頼できるexperimentの保存物のみを使用すること。
