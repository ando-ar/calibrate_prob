calibration_pipeline.source module

Upload the candidate file and execute the user's SQL without substitutions.

class calibration_pipeline.source.Source(connection: Connection)[ソース]

ベースクラス: object

同じSQLAlchemy接続で候補のアップロードとSQL実行を行う。

set_seed(seed: int) → None[ソース]

接続のSQL乱数を0〜2147483647の整数seedで初期化する。

upload(frame: DataFrame)[ソース]

候補を接続内の一時テーブルcalibration_candidatesに格納する。

execute_sql(sql: str, params: tuple = ()) → DataFrame[ソース]

SQLを実行し、結果をPolars DataFrameとして返す。

params はDBドライバー形式の位置引数としてバインドする。 結果表を返さないSQLではValueErrorを送出する。

execute_sql_file(path: Path) → DataFrame[ソース]

UTF-8（BOM可）のSQLファイルを読み込み、置換せず実行する。

calibration_pipeline.source.connect(*, sqlite: bool = False, sqlite_fixture: Path | None = None) → Generator[Source][ソース]

トランザクション内のSourceを提供するコンテキストマネージャー。

SQLiteはメモリ内DBを作り、指定されたfixtureをコピーする。 既定のRedshiftはREDSHIFT_HOST/DATABASE/USER/PASSWORDと任意のPORTを使う。 コンテキストを抜けると接続とengineを解放する。
