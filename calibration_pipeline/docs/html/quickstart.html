demo GUIで学習と推論を試す

Python 3.11以上とuvを使います。リポジトリを取得し、calibration_pipeline/ で実行してください。 依存関係の追加はありません。

uv sync --locked
uv run --locked python -m calibration_pipeline.demo_gui

ブラウザが開きます（既定は http://127.0.0.1:8000/）。学習タブと推論タブを切り替えられます。 フォームはSQLite実行例で事前入力されています。初回は「fixtureを再生成する」ボタンで examples/sqlite/ のデモデータを作り、そのまま「学習を実行する」を押します。 その後、推論タブで「推論を実行する」を押すと、最新の学習runで候補の確率を計算します。

ボタンを押すと本物のCLI（python -m calibration_pipeline.cli）が別プロセスで同期実行され、 完了後に同じページへ次の内容が表示されます。

タブ

表示内容

学習

状態とCLI出力、calibration_metrics.json（件数・実績率・ECE・Brier・ビン毎）、calibration_plot.svg、runディレクトリ

推論

状態とCLI出力、使用した学習run、calibrated_score の候補ごとの表

学習と推論のフォームはexperiment名（model name）・seed・config・SQL・入力ファイルを上書きできます。 推論では、使用する学習runを「最新」または過去の成功runから選べます（--train-run に相当します）。 生成物は experiments/demo_gui/<model_name>/... に保存され、Gitの対象外です。 入力が不正な場合はCLIのエラーメッセージがそのまま表示されます。

SQLiteでCLIから学習と推論を試す

demo GUIと同じ流れをコマンドで実行します。fixture生成には、同じリポジトリの ../synthetic_funnel/ が必要です。

uv sync --locked
uv run --locked python examples/sqlite/prepare_example.py
uv run --locked calibration-pipeline train --model-name sqlite_oubo_demo --sqlite --sqlite-fixture examples/sqlite/train/sqlite_fixture.db --config examples/sqlite/train/config.toml --sql examples/sqlite/train/train.sql
uv run --locked calibration-pipeline inference --model-name sqlite_oubo_demo --sqlite --sqlite-fixture examples/sqlite/train/sqlite_fixture.db --config examples/sqlite/inference/config.toml --sql examples/sqlite/inference/inference.sql --original-score examples/sqlite/inference/original_score.csv

学習結果は experiments/sqlite_oubo_demo/train/<run_id>/output/、推論結果は experiments/sqlite_oubo_demo/inference/<run_id>/output/ に保存されます。 推論の calibrated_score.csv には入力候補と同じ行順で確率列が加わります。 繰り返し実行すると新しいrunが作られます。DBはGitに含めず、上記スクリプトで再生成します。

Redshiftで実行する

uv sync --locked --extra redshift を実行し、REDSHIFT_HOST、REDSHIFT_DATABASE、 REDSHIFT_USER、REDSHIFT_PASSWORD を環境変数に設定します。 REDSHIFT_PORT の既定値は5439です。読み取り権限に加え、推論には一時テーブルの作成権限が必要です。

uv run --locked --extra redshift calibration-pipeline train --model-name my_model --config job/train.toml --sql job/train.sql
uv run --locked --extra redshift calibration-pipeline inference --model-name my_model --config job/inference.toml --sql job/inference.sql --original-score job/original_score.parquet

SQLiteのSQL例はRedshift向けに調整してください。設定・SQLの契約は入力・出力と実行の流れで説明しています。
